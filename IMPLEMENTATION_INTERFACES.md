# Integration contracts

Implementation working agreement. Public navigation is in docs/code-map.md.

Python 3.11+, standard library runtime, unittest tests. Host state is JSON-compatible dictionaries. The root controller owns uses, accounts, grants, policy, revisions and trial transitions. Other modules do not infer semantic permission.

Policy is a validated dict from config.py, matching spec baseline keys. Extra keys: strict_tokens (true), timeout_seconds (120), max_pending_trials (4), roots_limit (8), required_limit (16), read_page_chars (4000), max_read_pages (4), dependency_slice (64), history_limit (256), max_source_bytes (16777216), max_collection_bytes (134217728), jolt_echo (false), jolt_cooldown (6), daydreaming (true), recipes (local/broader). Counters take the complete list of chat message dictionaries and return int; capability describes exact/bounded/estimated/fixture.

collection.py owns Collection(data=None), with JSON-compatible .data. APIs: add(text, origin, label='', links=(), **metadata)->id; get(id)->dict or None; link(a,b, stream='default')->None; ingest(path)->id; catalogue(cursor=0, limit=10)->dict {items,next_cursor,complete}; read(id,start=0,limit=4000)->dict {text,start,end,next_cursor,complete,...}; search(phrase,cursor=None,page_size=10,work_bytes=65536,source_ids=None)->dict. .data has occurrences dict, order list, adjacency dict of list {target,stream}. Each occurrence: id,text,origin,label,version,representation,readable; immutable original source bytes retained base64 when ingested. Origin is operational (source/model/etc), never an epistemic type.

checking.py owns Checker(data=None), .data JSON-compatible, add(collection,source_id,phrase,start=0,end=None,comparison='literal',version='1')->check id; step(collection,slices=4,slice_bytes=65536)->list of scoped receipts. Recheck is add with new identity. Root owns installed conditional bindings, matching receipts and use changes. Checker receipt carries id,check_id,source_id,source_version,representation,comparison,checker_version,phrase,start,end,status,match_offsets,scan_complete. No match before full declared range complete. Built-in comparison literal only is acceptable; unsupported comparison explicit.

context.py owns compile_cut(collection, *, policy, account, invitation, required=(), roots=(), counter, recipe='local', extra_anchors=(), nonlocal_read=None)->Cut. account dict has id,focus (occurrence id),method (occurrence id),uses (list dict with occurrence,purpose,disposition,blocked,reason,id), context_cursors(dict). Cut has .messages (full chat messages), .input_tokens, .mode ('work'/'read'), .included (ids), .omissions (bounded notes), .inspections, .recipe, .to_dict(). Account cursors persist by in-place update. Include focus/method and immediate required anchors, label parked uses as examination only; participant_history off suppresses optional predecessor model text. Oversized required packet becomes explicitly incomplete reading and no full-response claim. Fixed roots/anchors and inspected edges bounded; stable rotating BFS, no relevance scores.

resources.py owns Ledger(data=None, *, max_calls=24,max_tokens=262144), .data JSON-compatible, reserve(key, amount, calls=1), dispatch(key), settle(key, usage or None), cancel(key), available(), paused. Reservation amount is total input+generation for that key; bundle calls supported or root reserves individual future keys. Usage dict fields input_tokens,output_tokens,cached_input_tokens,reasoning_tokens,reasoning_included; unknown conservatively charged. Duplicate settlement idempotent, post-dispatch timeout retained charge, overrun pauses. Expose simple read-only report().

providers.py owns ProviderResult(text,usage=None,metadata=None), ScriptedProvider(responses), DemoProvider(), OllamaProvider(model,base_url='http://localhost:11434',api_key_env='OLLAMA_API_KEY',think=None). Provider .name, .count_kind, count(messages)->int, generate(messages,*,max_tokens,timeout)->ProviderResult. Demo/scripted counters fixture-labelled, Ollama count estimated and explicit allow-estimates config. No arbitrary execution. Source and generated text never grant credentials or URLs. Document accounting provenance; don't fabricate missing counters or reveal credentials in errors.

engine.py root API: Engine.create(brief, policy=None, directory=None), Engine.load(directory), save(), add_account(brief, name=None), add_source(path), add_text(text,label=''), run(provider,steps=None), step(provider), status(), export_markdown(), set_gate(value), reset_attention(account_id=None), set_commitments(value), change_use(account_id,use_id,action,reason), add_use(account_id,occurrence,purpose), bind(account_id,use_id,source_id,phrase,start=0,end=None), check(source_id,phrase,...), jolt(account_id=None,kind='fresh'), policy dict and state dict. CLI calls these and may expose other APIs discovered during integration.
